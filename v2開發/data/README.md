# 餐廳推薦圖片資料

`restaurant_image_links.csv` 是從使用者提供的「餐廳圖片連結填寫表_照片不重複_找不到照片則換示意圖.docx」整理出的餐廳圖片 URL 對照表，依 `restaurant_id` 對應資料庫中的餐廳。原 Word 檔不放進專案；若要更新資料，可執行：

```powershell
.\.venv\Scripts\python.exe scripts\convert_restaurant_photo_docx.py --source 'C:\path\to\更新後的圖片連結表.docx'
```

匯入正式資料庫前，必須依 `v2開發流程.md` 新做完整備份並確認隔離還原，再使用 `scripts/apply_0011_existing.py`。推薦先顯示餐廳圖片；餐廳圖片缺漏或載入失敗時改用食物圖片，兩者皆不可用才顯示前端佔位圖。

目前 CSV 有 158 間餐廳：31 筆有餐廳圖片 URL，158 筆有食物圖片 URL；所有圖片 URL 均為 HTTPS，且沒有重複 URL。圖片仍由原網站提供，這份資料沒有複製或託管影像檔。

正式公開前要確認圖片使用授權／標示要求。外部圖片可能撤下、限制外連或變慢；目前會遞補到另一張圖片，兩張都失效才顯示佔位圖。載入時瀏覽器仍會向圖片來源網站送出請求，該網站會看到使用者 IP 與請求時間；前端已禁止傳送 Referer。若要長期穩定提供圖片，後續可在確認授權後改存自己的物件儲存。
