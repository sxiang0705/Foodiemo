# 目前介面互動圖

更新：2026-09-10。依目前 v2開發/frontend 程式核對，呈現現有頁面與事件，不把開發規劃當成已完成能力。此文件只新增互動說明，沒有修改功能。

**讀圖方式：**綠色表示已串接的餐廳流程；藍色表示保留的前端操作（資料可能待串接）；灰色表示示例。實線為現有導航或畫面操作；虛線為程式中預留的成功／保存流程，目前缺少 v2 後端支援，不能視為已可完成。

## 1. 整體導航

```mermaid
flowchart TB
    subgraph MAIN["主畫面：預設停在中間的拍照首頁"]
        direction LR
        M["回憶日曆<br/>資料待串接"] <-->|左右滑動| H["拍照首頁<br/>照片資料待串接"]
        H <-->|左右滑動| S["社群<br/>資料待串接"]
    end
    H -->|放大鏡| R["餐廳推薦：3 張卡片<br/>已串接 PostgreSQL"]
    R -->|頂端下拉，替換整批| R
    R -->|點卡片| D["餐廳詳情<br/>覆蓋在列表上"]
    D -->|關閉| R
    D -->|地圖按鈕| G["Google Maps<br/>另開視窗"]
    R -->|返回| H
    H -->|快門| C["拍照／相簿／取消"]
    C -.->|選完直接上傳；待串接| H
    H -->|鉛筆| E["照片編輯<br/>選圖、多選、Finish"]

    S -->|自己的貼文：留言| Q["留言頁<br/>Post／Enter；資料待串接"]
```

- 主容器從左到右為「回憶日曆 → 拍照首頁 → 社群」，預設中間首頁。手指往左滑向右側頁面，往右滑向左側頁面；短滑會回彈。
- 目前主入口依本機登入標記導向登入頁或首頁，這不等於後端身分驗證已完成。
- 子頁的返回路徑依原版保留；照片編輯會依 from=home／social 返回不同位置。
- 限動或鎖定中的子頁會通知主容器停止側滑。手機巢狀手勢尚未完成實機驗收。

## 2. 餐廳推薦：目前已串接部分

```mermaid
flowchart TD
    A["首頁：點放大鏡"] --> B["讀取最多 3 間真實餐廳"]
    B --> C{"讀取結果"}
    C -->|有資料| D["直向大圖卡列表"]
    C -->|沒有候選| Z["原列表位置顯示：沒有推薦"]
    C -->|失敗或逾時| X["原列表位置顯示：讀取失敗"]
    D -->|列表在頂端，向下拉過門檻| B
    Z -->|下拉重試| B
    X -->|下拉重試| B
    D -->|點任一卡片| E["詳情覆蓋層<br/>店名、分類、評分、時間、價位、地址、來源"]
    E -->|左上關閉| D
    E -->|地圖按鈕| F["另開 Google Maps"]
    D -->|頁面左上返回| A
    classDef ready fill:#E0F3E8,stroke:#278458,color:#153C2A;
    class A,B,C,D,Z,X,E,F ready;
```

- 下拉是整批替換，不追加列表，也沒有分頁按鈕。觸控與滑鼠皆有處理。
- 詳情讀取被點擊的卡片資料，不另外改成評論清單；底部區塊是資料來源說明。
- 缺照片使用明示的佔位圖，沒有提供的評分、價格、營業時間不造值。
- 資料少於 3 間就顯示實際數量；失敗後仍透過原本下拉恢復。
- 可直接開 search.html 核對公開餐廳資料，不表示其他頁面的帳號與私人資料已串接。

## 3. 照片、回憶與社群

```mermaid
flowchart TB
    H["拍照首頁"] -->|快門| A["底部選單"]
    A -->|拍照或相簿| F["取得照片"]
    A -->|取消| H
    F -.->|直接上傳成功，待串接| H
    H -->|鉛筆| E["照片編輯"]
    E -->|加圖／點縮圖| E
    E -->|單選／多選，顯示選取順序| E
    E -.->|Finish 保存成功，待串接| U["紀錄更新"]
    U -.-> H
    U -.-> M["回憶日曆"]
    U -.-> S["我的社群"]
    E -->|返回：依進入來源| H
    E -->|從社群進入時返回| S
    M -->|月份箭頭| M
    M -->|點有照片日期| V["限動"]
    V -->|左／右點擊，或每 3 秒| V
    V -->|下拉關閉或播放結束| M
    V -.->|刪目前單圖，待串接| U
    S -->|切換分頁| T["饗你推薦<br/>內建貼文示例"]
    T -->|切回| S
    S -->|多圖左右滑| S
    T -->|多圖左右滑| T
    S -->|留言圖示| Q["留言頁"]
    Q -.->|非空文字，Post／Enter 保存，待串接| Q
    Q -->|返回| S
    S -->|更多：編輯| E
    S -.->|更多：刪除，待串接且有原版缺陷| U
    classDef retained fill:#EDF2FA,stroke:#617797,color:#25364E;
    classDef demo fill:#F0F0F0,stroke:#888,color:#444;
    class H,A,F,E,U,M,S,V,Q retained;
    class T demo;
```

**兩條新增路徑不同：**快門選完照片直接上傳；鉛筆先進編輯頁，再按 Finish。不能將兩條路徑合併。

目前的限制：

- 照片、紀錄與留言 API 尚未串接，虛線表示原前端預期的成功行為。跨頁更新通知雖存在，仍有格式不一致等缺陷。
- 原編輯頁的「取消捨棄」仍會離開；社群「刪整篇」目前只呼叫刪首張照片。這是待修缺陷，不是要求保留的產品互動。
- 圖片上的數字表示選取順序，沒有拖曳排序功能。
- 地點只是固定 Kaohsiung 狀態切換；朋友標記只是 Tagged 示意，沒有選人／選餐廳介面。
- 按讚只改目前頁面的記憶體；檢舉與已具資格的共同編輯只有提示。
- 饗你推薦的留言按鈕顯示唯讀提示，不會進入真正的留言頁。這裡推薦的是貼文，與放大鏡的餐廳推薦不同。

## 4. 帳號、偏好與會員

```mermaid
flowchart TB
    L["登入頁"] -->|Sign up| S["註冊頁"]
    S -->|已有帳號| L
    S -.->|註冊 API 成功，待串接| O["四位 OTP：註冊驗證"]
    L -.->|帳號未驗證時| O
    O -.->|驗證成功，待串接| Q["六題偏好：二選一"]
    Q -->|逐題選擇後確認| Q
    Q -->|目前保存於本機，完成| H["拍照首頁"]
    L -.->|登入成功，待串接| H
    L -->|Forgot password| F["忘記密碼"]
    F -.->|寄送成功，待串接| R["四位 OTP：重設密碼"]
    R -.->|驗證成功，待串接| P["輸入兩次新密碼"]
    P -.->|重設成功，待串接| L
    G["Google 登入／註冊入口<br/>v2 尚未配置"] -.->|原版成功路徑直接到首頁| H
    H -->|頭像| U["個人頁"]
    U -->|名稱失焦儲存／點頭像換圖| U
    U -->|非會員點 Subscription| B["會員付款頁<br/>目前無真實金流"]
    K["社群：共同編輯／升級入口"] -->|未具資格| B
    B -->|取消，依來源返回| U
    B -->|取消，從社群進入時| K
    B -.->|升級成功後回來源，待串接| U
    B -.->|升級成功後回社群，待串接| K
    U -->|確認登出，清本機資料| L
    classDef retained fill:#EDF2FA,stroke:#617797,color:#25364E;
    classDef demo fill:#F0F0F0,stroke:#888,color:#444;
    class L,S,O,Q,H,F,R,P,U,B,K retained;
    class G demo;
```

- 六題依序為：飯／麵、葷食／素食、中式／美式、清淡／重口味、餐廳／街頭美食、獨享／多人分享。未選不能前進；目前偏好尚未保存至 PostgreSQL。
- 個人頁的改名／頭像操作保留，但後端保存未完成。登出可以清本機資料，不能因此宣稱後端 session 已撤銷。
- 會員頁保留卡片欄位及返回來源的互動，尚無 v2 升級服務與真實金流。已具會員旗標時，個人頁 Subscription 不再導向付款。
- 通知頁是靜態列表，可上下捲動及返回；它不是聊天頁。首頁中央人物膠囊與多數設定列沒有已綁定的操作。
- 原版保留的重置／除錯入口不代表管理功能已完成，不列為正常使用流程。
