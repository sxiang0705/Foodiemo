# 原始前端保留與本批差異

依據 前端原始程式碼/frontend。原始資料夾未修改。frontend-baseline.json 保存來源與 v2 雜湊；check_source.py 驗證來源未變、非允許變更檔案逐位元相等，以及推薦頁 CSS／靜態可見控制相同。

本批僅改動三個繼承檔案：

| 檔案 | 必要串接改動 |
| --- | --- |
| config.js | API 指向 v2 同源，不沿用 8001／舊外部設定；IndexedDB 使用 FoodiemoV2DB 避免混用 |
| search.html | 保留 CSS、靜態控制、直向卡片及下拉／詳情／地圖／返回操作；動態節點改安全文字；接 client helper、cursor、取消／最新回應保護；真實資料來源及缺值文案 |
| sw.js | v2 獨立快取名稱；HTML／JS 網路優先以免 helper 與頁面版本不一致；API／uploads 不快取；只清 v2 舊快取 |

env.js 與 google-auth-config.js 重新建立安全本機設定，不複製原真實設定；其他靜態頁面／圖片逐位元保留。不複製 code-workspace。新增 frontend/api/client.js 與缺照片佔位 SVG，後者明示「店家照片尚未提供」，不把示意餐廳照片宣稱為實拍。

資料差異僅在原位置顯示：狀態「真實資料」、評分未提供、價格未提供、營業時間請看地圖、資料來源說明。沒有新增搜尋、分類、分頁、收藏、評分輸入或公私開關。尚未動到照片編輯、日曆、社群與帳號頁的互動修正。

## 已執行對照

- 同一人工餐廳資料、390×844、Microsoft Edge：原版與 v2 卡片、圖片、文字框、來源標籤和返回按鈕幾何及樣式完全相同；最終對照截圖像素差異為 0。
- 觸控短拉不重取、超過門檻換整批；非頂端不刷新；滑鼠下拉可用。
- 原覆蓋詳情、來源說明、地圖及返回首頁路徑保留。
- 主容器仍三個 iframe、中間首頁、指定 tab、原側滑門檻、鎖定訊息與 resize 對齊。
- 截圖及執行明細放在 Git 忽略的 test-results；瀏覽器 fixture 身分只用於測試 context，不是登入功能。
- 手機實機相機、軟鍵盤、巢狀手勢尚未驗證。

## 明確待後續階段

原版的登入 gate、照片／日曆／社群頁、本機示意和固定貼文仍存在，但本批只完成餐廳推薦後端。登入／OTP、六題偏好保存、照片 CRUD、留言、會員及推薦事件尚未串接。現有原版的取消返回、刪整篇只刪首圖、快取同步等缺陷依流程在相應階段處理，不因複製前端就列完成。尚未新增 Google 問答步驟、公私開關或真實付款。
