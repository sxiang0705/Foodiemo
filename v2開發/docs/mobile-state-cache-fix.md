# 手機滑動與返回畫面修正

- iframe 隨外層移動，其 clientX 屬於移動中的座標系。轉換為外層 viewport 座標，避免慢速拖曳時位移回饋；不在拖曳途中啟用遮罩。
- 保留既有方向判斷、左右頁順序、翻頁門檻及控制項原生點擊。
- sessionStorage 暫存帳號所屬貼文中繼資料、月份與社群頁籤；首頁另保存一張最多 640px、350KB 的同源 JPEG 縮圖。每筆資料 10 分鐘有效，不保存原始照片。
- 先確認 Cookie 身分，顯示暫存，再背景讀取最新資料；相同結果不重畫。伺服器空陣列仍取代舊資料。
- 寫入成功清除貼文暫存，世代標記防止寫入前的讀取覆蓋；401、登出清除，切換帳號隔離。既有私人 API no-store 不變。
- 首頁不再在查詢完成前放預設照片；沒有照片時才顯示原預設圖。照片原檔仍需網路載入，並未宣稱完全消除延遲。\n- 畫筆返回使用瀏覽器歷史返回，讓支援 BFCache 的 Safari 保留首頁殼層；返回後仍會安靜確認最新照片。
- 若瀏覽器無法使用 BFCache，畫筆返回會啟用首頁載入閘門，等首頁 frameReady 才淡入，最長 2.2 秒後自動放行。
- 首頁 frameReady 同時等待中間照片與左上角頭像；頭像也保存一張帳號隔離的小縮圖。
- 登入導向同樣設置首頁載入閘門。中間首頁改為相機預覽容器；相片檔案仍保留作上傳相容性，不再作為主畫面。HTTPS 且獲得權限時使用 getUserMedia，HTTP LAN 則回退到快門拍照。
- 回憶頁返回保留所選月份；社群保留所選頁籤。未實作跨重載保留每張輪播位置及全部捲動位置。

## 驗證

navigation-touch.cjs：390 / 412px 下各 6 項通過，包含移動 iframe 的慢速左右拖曳、上下手勢、暫存先顯示後更新成空資料、帳號隔離與清除、照片選取、鉛筆與返回。
一般測試 49 passed；原版 CSS / 檔案保留檢查通過。
測試瀏覽器為 Edge Chromium 手機模擬，仍需 iPhone Safari 實機確認。

## 實機確認

重新整理手機頁面一次取得新版。慢速左右滑與上下滑應無反覆跳動；切到回憶更換月份後返回，月份應保留；編輯照片後返回應看到更新，登出後登入其他帳號不能看到先前資料。

- 相機串流在 index.html 的左右頁切換時保持，不再因 pageVisibility 隱藏而停止；中間快門直接擷取 video frame 上傳，只有相機不可用才回退到拍照／相簿選單。
