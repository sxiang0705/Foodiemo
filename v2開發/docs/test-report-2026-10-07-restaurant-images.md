## 仍需留意

- 此瀏覽器 live 驗收載入了當次推薦中的圖片，並未逐一向 189 個外部 URL 發出請求。某些來源之後仍可能限制外連、改網址或離線；前端有食物圖及本機佔位圖遞補。
- 圖片由原網站託管，尚未逐一核實授權／署名要求；專題 demo 可以先使用，對外公開前應確認授權。外部網站會看到圖片請求的使用者 IP 與時間；已設定不送 Referer。
- `scripts/check_source.py` 目前仍因原始前端 `edit.html` 的來源雜湊與既有基線不符而失敗；本次沒有修改「前端原始程式碼」目錄。需另行比對該檔案差異，再決定是否更新基線。
- 尚未在實體 iPhone Safari 逐一驗證 158 筆來源；瀏覽器測試使用 Microsoft Edge，實機驗收可以確認圖片來源在手機網路下的載入速度。
